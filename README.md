# Web приложение - UI Framework

Рамочный UI для веб-приложения с поддержкой аутентификации и тем.

## Возможности

- 🎨 Стандартное верхнее меню с логотипом и информацией об аккаунте
- 🌓 Переключение между светлой и темной темой
- 🔐 Полная система регистрации и входа
- 🆔 **Яндекс ID OAuth 2.0 аутентификация**
- 📧 Регистрация по email с подтверждением
- 🔌 Интеграция с API сервера для аутентификации
- 👤 Проверка статуса пользователя (guest/авторизованный)
- 🔑 Поддержка XSRF токенов для безопасности
- ✉️ Подтверждение email по ссылке (в режиме localStorage)
- 📱 Адаптивный дизайн для всех устройств
- 💾 Сохранение настроек в localStorage
- ⚙️ Гибкая настройка: API или localStorage режим

## Быстрый старт

### Режим API (с подключением к серверу)

1. Откройте `config.html` в браузере
2. Укажите хост API (например: `example.com`) и название базы данных
3. (Опционально) Укажите Yandex OAuth Client ID для авторизации через Яндекс ID
4. Сохраните настройки
5. Откройте `register.html` или `login.html`
6. Приложение автоматически проверит статус пользователя через API
7. При регистрации данные будут отправлены на сервер
8. При входе будет выполнена аутентификация через API или Яндекс ID

### Режим localStorage (демо без сервера)

1. Откройте `config.html` в браузере
2. Отметьте галочку "Использовать режим localStorage"
3. Сохраните настройки
4. Откройте `register.html` в браузере
5. Зарегистрируйте пользователя с email и паролем
6. Скопируйте ссылку подтверждения со страницы успеха
7. Перейдите по ссылке для активации аккаунта
8. Войдите через `login.html`
9. Попадете на главную страницу `index.html`

### Система аутентификации

Полностью работающая система с тремя методами аутентификации:

#### 1. Аутентификация через Яндекс ID (OAuth 2.0)

Для использования авторизации через Яндекс ID:

1. **Зарегистрируйте приложение в Яндекс OAuth:**
   - Перейдите на https://oauth.yandex.com/
   - Создайте новое приложение
   - Добавьте Callback URL: `http://your-domain.com/callback.html` (или `http://localhost/callback.html` для локальной разработки)
   - Скопируйте Client ID

2. **Настройте Client ID в приложении:**
   - Откройте `config.html`
   - Вставьте Client ID в поле "Yandex OAuth Client ID"
   - Сохраните настройки

3. **Использование:**
   - На страницах login.html и register.html появится кнопка "Войти через Яндекс ID"
   - При клике происходит перенаправление на страницу авторизации Яндекс
   - После успешной авторизации пользователь возвращается на callback.html
   - Приложение получает access token и информацию о пользователе
   - Пользователь автоматически перенаправляется на главную страницу

**Полученные данные от Яндекс ID:**
- Email пользователя
- ID пользователя
- Отображаемое имя
- Реальное имя
- Аватар

#### 2. Режимы работы

Полностью работающая система с двумя режимами работы:

**Режим API:**
- Проверка статуса пользователя через `GET /xsrf`
- Сохранение XSRF токена для POST запросов
- Регистрация через `POST /_m_new/18?up=1&next_act=inform`
- Вход через `POST /auth?JSON`
- Отображение имени пользователя (или "guest") в навигации
- Скрытие информации об аккаунте для гостевых пользователей

**Режим localStorage:**
- Регистрация с валидацией полей
- Подтверждение email через токен
- Вход с проверкой подтверждения email
- Защита страниц от неавторизованного доступа
- Автоматический редирект на login

## Yandex ID OAuth 2.0 Integration

### Технические детали

**Процесс авторизации:**

1. Пользователь нажимает "Войти через Яндекс ID"
2. Приложение перенаправляет на `https://oauth.yandex.ru/authorize` с параметрами:
   - `response_type=token` (implicit flow)
   - `client_id` (из настроек)
   - `redirect_uri` (callback.html)
3. Пользователь авторизуется на Яндексе и разрешает доступ
4. Яндекс перенаправляет обратно на `callback.html#access_token=...`
5. JavaScript извлекает access_token из URL fragment
6. Приложение запрашивает информацию о пользователе через API:
   - `GET https://login.yandex.ru/info?format=json`
   - Header: `Authorization: OAuth {access_token}`
7. Данные пользователя сохраняются в localStorage
8. Пользователь перенаправляется на главную страницу

**Безопасность:**
- Используется OAuth 2.0 Implicit Flow для клиентских приложений
- Access token хранится в localStorage
- Срок действия токена отслеживается и проверяется
- При истечении токена требуется повторная авторизация

**API endpoint для получения данных пользователя:**
```
GET https://login.yandex.ru/info?format=json
Authorization: OAuth {access_token}

Ответ:
{
  "id": "user_id",
  "login": "username",
  "default_email": "user@yandex.ru",
  "display_name": "Имя Фамилия",
  "real_name": "Полное имя",
  "default_avatar_id": "avatar_id"
}
```

## API Integration

### Настройка подключения

Приложение поддерживает интеграцию с backend API согласно спецификации:

**Проверка статуса пользователя:**
```
GET https://{host}/{db}/xsrf
Ответ: {"_xsrf":"token","token":"auth_token","user":"username","role":"role","id":"user_id","msg":""}
```

**Регистрация пользователя:**
```
POST https://{host}/{db}/_m_new/18?up=1&next_act=inform
Параметры: _xsrf={token}, t18={email}, t20={password}
```

**Вход в систему:**
```
POST https://{host}/{db}/auth?JSON
Параметры: db={db}, login={email}, pwd={password}
Ответ: {"_xsrf":"token","token":"auth_token","id":"user_id","msg":""}
```

### Хранение токенов

- XSRF токен сохраняется в localStorage и используется для всех POST запросов
- Токен аутентификации сохраняется после успешного входа
- Информация о текущем пользователе обновляется при каждой проверке статуса

## Важно

⚠️ Приложение поддерживает три режима работы:

1. **API режим** - полная интеграция с backend сервером
2. **Яндекс ID OAuth** - авторизация через Яндекс ID (требует Client ID)
3. **localStorage режим** - демонстрационная версия для тестирования UI

Для production необходимо:
- Настроить CORS на сервере
- Использовать HTTPS/SSL (обязательно для OAuth)
- Зарегистрировать приложение в Яндекс OAuth и получить Client ID
- Настроить правильный Callback URL в настройках Яндекс OAuth
- Настроить обработку CSRF токенов
- Реализовать серверную валидацию
- Настроить отправку email для подтверждения регистрации
- Защитить access token от XSS атак

### Настройка Яндекс OAuth для production

1. Зайдите на https://oauth.yandex.com/
2. Создайте новое приложение
3. В разделе "Платформы" выберите "Веб-сервисы"
4. Укажите Callback URI: `https://your-domain.com/callback.html`
5. В разделе "Доступ" выберите необходимые права:
   - login:email - доступ к email адресу
   - login:info - доступ к имени, аватару и другой информации
6. Скопируйте Client ID и укажите его в настройках приложения

**Важно:** В production обязательно используйте HTTPS, так как OAuth 2.0 требует защищенного соединения.
